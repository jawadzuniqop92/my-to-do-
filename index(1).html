What fits here?

Portfolios, business introductions, event pages, and simple landing pages.

What needs different hosting?

WordPress, PHP, databases, file folders, build pipelines, shops processing payments, or apps collecting customer data.

Hosted scripts can run in isolation, but forms, API calls, cookies, and browser storage are restricted. Images, fonts, and media must be embedded or use HTTPS URLs.

External resources have their own costs and privacy implications. Do not put API keys or passwords in HTML.

Publishing rules

Publish only content you have permission to use. No phishing, impersonation, malware, spam, illegal material, or attempts to bypass limits.

ZUNIQ can suspend a site or revoke an invitation. Expired or revoked access also takes its websites offline.

Your invitation key is held only in this tab’s memory. Do not share it. Public page HTML can be read by anyone. Delete a website to remove its current and previous HTML from the active database; provider backups may remain.

From file to website

Start small. Publish carefully.

For website creators

  1. Get an invitation key from ZUNIQ Studio.
  2. Enter your name, website name, and desired address.
  3. Upload a self-contained HTML file.
  4. Preview the layout on desktop and mobile.
  5. Accept the publishing rules and publish.
  6. Open the returned live link and check it.

To update: open your website with Edit, upload the new HTML, and publish. Restore swaps the current HTML with the previous version. Download a backup first.
